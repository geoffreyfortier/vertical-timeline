# Vertical Timeline Web Page

This repository contains a static HTML/CSS implementation of a vertical, alternating timeline layout. It is designed to present chronological events in a clear, readable format, with support for long-form text and responsive behavior on mobile devices.

The project uses no JavaScript and no build tools. All layout, styling, and responsiveness are handled with plain HTML and CSS.

---

## Features

- **Pure HTML + CSS**
  - No frameworks or dependencies
  - Suitable for static hosting

- **Alternating Timeline Layout**
  - Events alternate left and right along a central vertical line
  - Each event consists of:
    - A content box
    - A connecting horizontal line
    - A date label aligned to the timeline

- **Responsive Design**
  - Automatically adjusts typography and spacing for smaller screens
  - Mobile styles prioritize readability for long text blocks

- **Accessible, Readable Typography**
  - Uses widely available web-safe and Google Fonts
  - Designed for long paragraphs without excessive visual clutter
